# 🌤️ Weather App (React)

A modern and responsive Weather Application built using React.js that fetches real-time weather data using the OpenWeatherMap API.

## ✨ Features

- 🔍 Search weather by city name
- 🌡️ Real-time temperature display
- 💧 Humidity, wind speed, and pressure
- 🌤️ Dynamic weather conditions
- 📱 Fully responsive (mobile-friendly)
- ⚡ Fast API fetching with clean UI

---

## 🛠️ Tech Stack

- ⚛️ React.js
- 🎨 HTML5 & CSS3
- 💻 JavaScript (ES6)
- 🌐 REST API

---

## 🌐 API Used

- OpenWeatherMap API
